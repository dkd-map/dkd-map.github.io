Dynamic DKDM Framework

Static interaction maps are essential for representing what molecules interact, but they cannot capture how a biological system behaves over time. Understanding disease dynamics requires knowing how signaling networks evolve, which regulatory interactions are rate-limiting, and how the system responds to perturbations such as gene knockdown or pharmacological inhibition. This is the domain of dynamic computational modeling.

The Dynamic DKDM Framework extends the static molecular map into the dimension of time by providing parametric ordinary differential equation (ODE) models for each of the 24 renal cell types in DKDM. These models were generated using the SPADAN framework, in which each node in the cell-type-specific intracellular signaling network is represented as a molecular species governed by a differential equation, and each directed regulatory interaction is encoded as a rate term. Because large-scale quantitative time-series data from human DKD kidney tissue are not currently available, model parameters are defined within biologically plausible ranges rather than fixed numerically. This parametric approach encodes the structural logic of each cell type’s signaling network while remaining flexible for future data-driven refinement.

What you can do with the Dynamic DKDM models

  • Download any cell-type-specific ODE model in SBML format for direct import into simulation environments including COPASI, tellurium, and libSBML-based tools
  • Perform sensitivity analysis to identify which regulatory interactions most strongly influence system dynamics in a cell type of interest
  • Simulate perturbations such as gene knockout, overexpression, or pharmacological inhibition in silico
  • Parameterize the scaffold model using your own experimental time-series data
  • Compare regulatory architectures across cell types to identify shared versus cell-type-specific dynamic features
