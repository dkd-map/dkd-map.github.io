Cell–Cell Interaction Network

Which kidney cell types talk to each other in diabetic kidney disease, and through which ligand–receptor pairs. Every edge below is one directed ligand→receptor channel from a sender cell type to a receiver cell type; hover an edge to read the pairs it carries, or pick a cell type to isolate it.

⬇ Download Excel How this network was built

Cell types are placed alphabetically around the circle, so the layout is identical on every visit and between machines. Arc thickness is the number of ligand–receptor pairs carried; arrowheads point from sender to receiver. Self-signalling is drawn as a loop outside the ring.

Scope of this release. The interactive network above contains the 59 ligand–receptor records currently curated into receiver cell types . The summary figures below were computed on the complete 24-cell-type matrix, so they cover more interactions than the network currently displays. Adding the remaining receivers to assets/data/cell-cell-interactions.csv extends the network automatically — no other change is needed.
