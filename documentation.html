1. Overview

The Diabetic Kidney Disease Map (DKDM) is a freely accessible, cell-resolved, FAIR-compliant systems biology resource that consolidates heterogeneous biological knowledge about DKD into a unified, computable, and interactively explorable platform. It integrates five complementary evidence layers — literature mining, transcriptomics, proteomics, genome-wide association data, and non-coding RNA — yielding a curated inventory of 831 high-confidence DKD-associated biomolecules mapped onto 24 renal cell types.

The platform provides four main interactive surfaces:

  • Cell Types — 24 kidney cell types, each with a MINERVA annotated map, ODE model, and downloadable analysis results
  • Gene Search — search any gene to see its presence across cell types, centrality rankings, cell–cell communication role, miRNA regulators, and associated pathways
  • Pathway Explorer — browse pathway enrichment results by cell type or search by pathway name to see which cell types share it
  • Dynamic DKDM — an interactive network atlas for exploring and simulating parametric ODE models for each cell type

Two additional network maps cover intercellular communication (Cell–Cell Interaction Map) and post-transcriptional regulation (miRNA–Target Regulatory Network).

2. Data Sources

Kidney Precision Medicine Project (KPMP) single-cell atlas

The 24 renal cell types and their gene expression profiles are derived from the Kidney Precision Medicine Project (KPMP) single-cell RNA sequencing atlas, comprising over 100,000 human kidney cells. Cell-type-specific expression profiles were used to filter protein–protein interactions, ligand–receptor pairs, and miRNA–target relationships to ensure that only interactions supported by actual expression evidence in human kidney tissue are represented.

STRING — Protein–Protein Interactions

Intracellular protein–protein interaction (PPI) networks for each cell type were constructed using the STRING database. Interactions were filtered by cell-type-specific expression to generate cell-resolved PPI networks. These networks form the structural basis for centrality analysis and the ODE models.

SIGNOR — Signaling Pathways

Directed regulatory interactions (activation, inhibition, post-translational modifications) were sourced from the SIGNOR database. These provide the causal directionality needed to build dynamic models — each directed interaction becomes a rate term in the ODE system.

KEGG & Reactome — Pathway Enrichment

Pathway enrichment analysis was performed using Enrichr, which queries multiple pathway libraries including KEGG and Reactome. Results include pathway names, gene set identifiers, p-values, FDR-adjusted q-values, and the overlapping gene lists. These data power the Pathway Explorer.

SEPDB & CellChatDB — Cell–Cell Communication

The Cell–Cell Interaction Map integrates high-confidence secreted ligands from SEPDB with experimentally validated ligand–receptor pairs from CellChatDB, filtered by cell-type-specific expression from the KPMP atlas. The resulting network comprises 498 directed intercellular interactions across all 24 cell types.

miRTarBase & GSE51674 — miRNA Regulation

Dysregulated miRNAs were identified through differential expression analysis of the human kidney microarray dataset GSE51674 using limma with Benjamini–Hochberg correction (FDR ≤ 0.05), yielding 128 reproducibly dysregulated miRNAs. Only experimentally validated miRNA–target relationships from miRTarBase were retained, ensuring biological relevance.

MINERVA Platform

The annotated disease map is deployed on the MINERVA platform, which provides interactive visualization, element-level annotations, references, and evidence tracking for every molecular component and interaction.

FAIRDOMHub

All underlying data — centrality measurements, pathway enrichment results, GO enrichment results, PPI networks, and biological process results — are publicly deposited on FAIRDOMHub in compliance with FAIR data principles.

3. Methods

Marker identification and cell-type assignment

The 24 renal cell types were identified from the KPMP single-cell atlas using established marker genes. Each cell type's expression profile was used to filter downstream interaction networks, ensuring cell-type specificity.

Protein–protein interaction (PPI) network construction

For each cell type, STRING PPIs were filtered to retain only interactions between proteins encoded by genes expressed in that cell type. This produced 24 cell-type-specific intracellular PPI networks.

Network centrality analysis

Six centrality measures were computed for each node in every cell-type PPI network:

  • Degree centrality — number of direct connections
  • Betweenness centrality — how often a node lies on shortest paths between others
  • Closeness centrality — average inverse distance to all other nodes
  • Eigenvector centrality — connection to well-connected neighbors
  • PageRank — iterative importance score based on connected nodes
  • Harmonic centrality — sum of inverse distances to all other nodes

A composite centrality rank orders genes within each cell type. Hub genes (high centrality) are prioritized as potential therapeutic targets. These data are available in the Gene Search results and as downloadable CSV files.

Pathway enrichment analysis

For each cell type, the gene set was tested for enrichment against pathway libraries (KEGG, Reactome, WikiPathways) using Enrichr's hypergeometric test. Results include p-values, FDR-adjusted q-values, enrichment ratios, and overlapping gene lists. The Pathway Explorer provides interactive access to these results with FDR filtering.

Gene Ontology (GO) enrichment

GO enrichment was performed for Biological Process, Molecular Function, and Cellular Component ontologies. Results are available as downloadable files from each cell type's resource panel.

ODE model construction (SPADAN framework)

Parametric ordinary differential equation (ODE) models were generated for each cell type using the SPADAN framework. Each node in the cell-type-specific signaling network is represented as a molecular species governed by a differential equation, and each directed regulatory interaction (from SIGNOR) is encoded as a rate term. Because large-scale quantitative time-series data from human DKD kidney tissue are not currently available, model parameters are defined within biologically plausible ranges rather than fixed numerically. This parametric approach encodes the structural logic of each cell type's signaling network while remaining flexible for future data-driven refinement.

SBML export

All ODE models are exported in Systems Biology Markup Language (SBML) format, making them directly importable into standard simulation environments including COPASI, tellurium, and libSBML-based tools. The Dynamic DKDM web app parses these SBML files client-side to render interactive network visualizations.

Druggability scoring

Computational druggability scores and drug–target interaction predictions were computed for over 1,200 compound–target pairs, providing a therapeutic prioritization layer on top of the molecular network.

4. How to Use Each Feature

Gene Search

The Gene Search page lets you look up any gene symbol and instantly see its role across the entire DKDM resource.

  • Search: Type a gene symbol (e.g., TP53, AKT1, VEGFA) in the search bar. Autocomplete suggestions appear as you type. Press Enter or click Search.
  • External links: Each result includes direct links to NCBI Gene, UniProt, HGNC, Open Targets, and KEGG for that gene.
  • Cell type presence: See which of the 24 kidney cell types contain this gene, with links to open the Dynamic DKDM network for each cell type.
  • Centrality table: If the gene appears in centrality analyses, its rank and centrality scores (degree, betweenness, PageRank) are shown per cell type.
  • Cell–cell communication: If the gene acts as a ligand or receptor in intercellular signaling, the relevant cell types are listed.
  • miRNA regulation: Validated miRNA–target interactions are shown with experiment type and PubMed references.
  • Pathways: Enriched pathways containing this gene are listed per cell type, with links to the Pathway Explorer.
  • Direct linking: You can link directly to a gene result using gene-search.html?gene=SYMBOL.

Pathway Explorer

The Pathway Explorer provides two complementary ways to explore enrichment results.

  • Browse by Cell Type: Select a cell type from the dropdown to see all enriched pathways sorted by FDR. Use the FDR filter to control significance stringency. Click "Show" next to any pathway to reveal the overlapping genes, each linking back to Gene Search.
  • Search by Pathway Name: Type a pathway name or keyword (e.g., "inflammasome", "insulin signaling") to find which cell types share that pathway. Results show per-cell p-values, FDR, and gene overlaps.
  • Pathway database links: Each pathway links to its source database (Reactome, KEGG) for full pathway context.
  • Direct linking: You can link directly to a pathway search using pathway-explorer.html?q=Pathway+Name.

Dynamic DKDM

The Dynamic DKDM web app provides an interactive network atlas for each cell type's ODE model.

  • Network visualization: Each cell type's signaling network is rendered as an interactive graph. Nodes represent molecular species (genes, proteins, RNA); edges represent regulatory interactions.
  • Gene search within a network: Use the search bar in the network view to find a specific gene. Matching nodes are highlighted and centered; non-matching nodes are dimmed.
  • Node details: Click any node to see its clean gene symbol, species type, and external database links (NCBI Gene, UniProt, HGNC, Open Targets).
  • Filtering: Filter nodes by type (gene, protein, RNA) to focus on specific molecular layers.
  • Download: Download the SBML model for any cell type for use in simulation tools.

Cell Types

The Cell Types page presents all 24 renal cell types as a visual grid.

  • Click any cell type card to open a resource panel with links to its MINERVA map, Dynamic DKDM model, and analysis results.
  • Download cell-type-specific files: biological process results, network centrality measurements, pathway enrichment results, and PPI networks.

Cell–Cell Interaction Map

The interactive CCI map visualizes 498 directed ligand–receptor interactions between cell types. Explore which cells send and receive signals, and download the full network as CSV.

miRNA–Target Regulatory Network

The interactive miRNA map shows 128 dysregulated miRNAs and their validated target genes. Explore regulatory relationships and download the full network as CSV.

5. Data Formats

SBML models (.xml)

Each cell type's ODE model is provided in SBML Level 3 format. Species IDs use suffixes to denote molecular type:

  • _g — gene (DNA)
  • _p — protein
  • _rna — RNA transcript
  • _u — ubiquitinated form (in select cell types)

The Dynamic DKDM web app automatically strips these suffixes for display, showing clean HGNC gene symbols. When working with SBML files directly, use the suffix to distinguish molecular species of the same gene.

Network centrality CSV

Columns: gene, degree_centrality, betweenness_centrality, closeness_centrality, eigenvector_centrality, pagerank, harmonic_centrality, centrality_rank

Pathway enrichment Excel (.xlsx)

Sheet PathwayEnrichmentResults_Top30 with columns: id, geneSet, link, size, overlap, expect, enrichmentRatio, pValue, FDR, gene_count, genes. The genes column contains semicolon-separated gene symbols.

Cell–cell interaction CSV

Columns: Ligand, Ligand UniprotID, Ligand CellType, Receptor, Receptor UniprotID, Receptor CellType, evidence, annotation, interaction_name

miRNA–target interaction CSV

Columns: miRNA, Target Gene, Interaction Type, Prediction Score, Experiment, Reference (PMID)

JSON indices (web app)

The Gene Search and Pathway Explorer pages are powered by two JSON indices:

  • gene-index.json — per-gene summary aggregating cell types, centrality, CCI role, miRNA regulation, and pathways
  • pathway-index.json — per-pathway summary with cell-type-specific enrichment statistics and gene lists

These are generated from the source data files and can be regenerated using the build script.

6. FAQ

What does the _g / _p / _rna suffix mean?

In the SBML models, each gene can appear as multiple molecular species — for example, TP53 as a gene (TP53_g), as a protein (TP53_p), or as an RNA transcript (TP53_rna). The Dynamic DKDM web app and Gene Search display clean gene symbols without these suffixes. When working with raw SBML files, the suffix tells you which molecular form of the gene that node represents.

Why are some pathways missing gene lists?

One cell type (B Cell) has pathway enrichment results without gene-level overlap data in the source file. For this cell type, pathway names and statistics are available, but the gene list is empty. All other cell types include full gene lists.

How were the 24 cell types chosen?

The cell types were identified from the KPMP single-cell RNA sequencing atlas of over 100,000 human kidney cells, covering both the nephron (from podocytes to collecting duct) and the interstitial/vascular compartments. They represent the major cell populations relevant to DKD pathology.

Can I use the ODE models for quantitative simulation?

The models are parametric — they encode the structural logic of each cell type's signaling network with biologically plausible parameter ranges, not fixed values calibrated to time-series data. They are suitable for structural analysis, sensitivity analysis, and qualitative perturbation studies. For quantitative simulation, you would need to calibrate parameters using your own experimental data.

How do I cite DKDM?

Please cite: Kiyanpour F, et al. DKDM: A Multi-Scale Digital Resource for Diabetic Kidney Disease. The full citation will be announced here once the manuscript is published.

Is the data freely available?

Yes. All data are publicly available on FAIRDOMHub and GitHub under FAIR principles. The MINERVA map, Dynamic DKDM app, and all downloadable files are free to use for research purposes.

How do I report an issue or suggest an improvement?

Please use the GitHub repository to file issues or contact the team directly.
